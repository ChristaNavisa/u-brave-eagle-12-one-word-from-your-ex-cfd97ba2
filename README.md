## The entry

> Practice

He was just practice — for the real one.

## How it works

`main.ts` writes that single word to `/output/entry.txt` (8 characters, valid UTF-8, one word, no trailing newline) and validates it first: 1–24 characters, not only whitespace, exactly one word.

Run it with Node 22.18 or later:

```sh
node main.ts
```
